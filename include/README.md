# include/

全组共用的 C 头文件。协议常量只在这里改一处，禁止在各 `.c` 里重写魔数和端口。

## 计划文件

- `frag_v1.h`：`magic` `0x4641`、`ver`、指令码、错误码、端口、16384 / 1024 / 1200
- 编解码声明（实现在 `src/common/`）

## 规则

| 类别 | 说明 |
|------|------|
| GitHub | 提交全部 `.h`（不含生成物） |
| gitignore | 不忽略本目录 |
| 本地 | 与 GitHub 应一致；不要长期只改本机头文件不推送 |
| 只读 | 无；但改字段 = 改协议 |
| 可编辑 | `.h` 与本 README。彭维护编解码声明；王补充房间/中继；改宽度须升 `ver` 并改 `docs` 约定 |

种子不得出现在任何结构体字段中。

# include/

全组共用的 C 头文件。协议常量只在这里改一处。

| 文件 | 内容 |
|------|------|
| `common.h` | 魔数、版本、指令码、错误码、端口、块长 |
| `fa_stream.h` | 收发状态机与唤醒 |
| `punch.h` | 打洞 / 探测 / 通告 |
| `ui_state.h` | 案情板状态 |
| `config.h` | 主机名解析与套接字辅助 |
| `log.h` | 日志 |

改字段等于改协议，须同步 [`docs/碎片档案_v1格式约定.md`](../docs/碎片档案_v1格式约定.md) 并升 `ver`。种子不得出现在任何结构体字段中。

# src/punch/

打洞客户端、探测、局域网通告。中继**服务端**在 `src/relay/`，不要写在这里。

## 范围

- 一个 UDP fd：探测、打洞、打洞后子包
- `JOIN_OK` 后再 `PROBE`，带已分配 `peer_id`
- 通告 37404；实验 7 连房主互传 TCP 做 `MANIFEST_REQ`
- 反射地址为 0 不得对发

## 规则

| 类别 | 说明 |
|------|------|
| GitHub | 提交客户端源码与 README |
| gitignore | 不忽略 |
| 本地 | NAT 类型记录写入 `docs` 或 `tests` 步骤，不要提交家庭公网 IP 名单到仓库 |
| 只读 | 「同一 fd、禁止另建 socket」 |
| 可编辑 | 打洞与通告（刘主责）。实验 9 不得把中继完成写成打洞成功 |

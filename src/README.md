# src/

全部实现。按模块分子目录，**不要**按成员姓名建目录。

| 子目录 | 模块 | 主责 |
|--------|------|------|
| `common/` | 报文编解码、TCP 读状态机、唤醒通道 | 彭 |
| `tracker/` | 房间服务：加入、心跳、名单、探测登记 | 王 |
| `relay/` | 中继转发，与房间服务同机 | 王 |
| `generate/` | 本局生成、切块、摘要、落盘 | 陈 |
| `transfer/` | 要块/给块、位图、HAVE、select | 彭 |
| `punch/` | 探测、打洞客户端、局域网通告 | 刘 |
| `ui/` | 界面与路径显示 | 刘 |

## 规则

| 类别 | 说明 |
|------|------|
| GitHub | 提交 `.c` `.h` 与各子目录 README；不提交编译产物 |
| gitignore | 根目录 `/tracker` `/client` 是**二进制名**，不是本目录。`src/tracker/` 必须跟踪 |
| 本地 | 可有 `.o`、本机 `Makefile` 生成的可执行文件（放仓库根时被忽略） |
| 只读 | 各子目录 README 中的「禁止」条款（与约定冲突时以约定为准） |
| 可编辑 | 模块源码：优先改自己主责目录；跨目录改动在 PR/提交说明里写清 |

可执行文件建议：`tracker`（含中继）、`client`，由根目录 `Makefile` 链接。

# src/ui/

界面线程。不在网络套接字上直接读写；操作时向唤醒通道写 1 字节。

## 可显示

局号、昵称、整文件摘要、块进度、来源、路径类型。

**禁止**显示种子。

## 规则

| 类别 | 说明 |
|------|------|
| GitHub | 提交 UI 源码与资源引用（资源本体在 `assets/`） |
| gitignore | 不忽略本目录；不要把截图当源码提交（截图走 `captures/` 且默认忽略） |
| 本地 | 主题/窗口布局可本机调 |
| 只读 | 禁止显示种子；路径四类文案与约定第 9 节一致 |
| 可编辑 | 界面（刘主责）。房间表/位图访问须加锁 |

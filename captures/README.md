# captures/

实验用的 pcap、终端日志、界面截图、录像。

## 规则

| 类别 | 说明 |
|------|------|
| GitHub | **只提交本 README**。不要提交 `.pcap` `.pcapng` `.log` `.zip` `.mp4` |
| gitignore | 上列后缀已忽略；`!captures/README.md` 保证本说明可跟踪 |
| 本地 | 抓包与录像放这里或移动硬盘；文件名写进 `docs`/`tests`（如 `exp1_tcp_sticky.pcap`） |
| 只读 | 无 |
| 可编辑 | 本 README。不要用 `git add -f` 强行加进大文件 |

答辩材料单独打包。抓包须能看出字节序，并与界面路径类型一致。

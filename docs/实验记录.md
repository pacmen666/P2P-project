## 实验 4 套接字选项

责任人：刘。家庭公网地址不写入本表。

「选项」列仅列 `setsockopt` / `getsockopt`。`fcntl(F_SETFL, O_NONBLOCK)` 与 `connect` 后 `getsockopt(SO_ERROR)` 单独成行。UDP 37404 与房间探测口 37402 不同。正式中继为 `relay_server`（37405）。

| 模块 / 套接字 | 文件 | 选项 / 机制 | 用途 |
|---------------|------|-------------|------|
| 房间 TCP 监听 | `src/tracker/room_server.c` | `SO_REUSEADDR` | 重启后快速绑定 37401 |
| 房间 UDP 37402 | `src/tracker/room_server.c` | `SO_REUSEADDR` | 探测 PROBE / PROBE_ACK |
| 中继 TCP 37405 | `src/relay/relay_server.c` | `SO_REUSEADDR`；非阻塞收发队列 | 重启绑定；BIND/WRAP 转发 |
| 刘侧互传 listen | `src/ui/client_main.c` | `SO_REUSEADDR` | 临时 TCP 端口 |
| 彭侧 peer listen | `src/transfer/transfer.c` | 无 `SO_REUSEADDR`；`fcntl` → `O_NONBLOCK` | 临时端口；与 `select` 同线程 |
| 打洞/探测/通告 UDP 37404 | `src/punch/udp_sock.c` | `SO_BROADCAST`、`SO_REUSEADDR`、`SO_REUSEPORT`（若支持）；`fcntl` → `O_NONBLOCK` | ANNOUNCE；本机多实例 |
| 彭侧 peer TCP | `src/transfer/transfer.c` | `SO_KEEPALIVE`；`fcntl` → `O_NONBLOCK`；`getsockopt(SO_ERROR)` | 长连接；非阻塞 `connect` |
| 刘侧房间 TCP | `src/ui/client_main.c` | `fcntl` → `O_NONBLOCK` | 连 Tracker |
| 彭侧房间 TCP | `src/transfer/client_main.c` | `fcntl` → `O_NONBLOCK`；`getsockopt(SO_ERROR)` | 连 Tracker |
| 实验辅助 | `src/common/config.c` | `getsockopt`：`SO_TYPE`、`SO_RCVBUF`、`SO_SNDBUF`；`SO_REUSEADDR` 开/关对比 | 只读类型与二次 bind |

打洞 UDP 使用 `sendto`。本网 `connect` 非阻塞，超时 1.5 秒。2026-10-12 WSL：`make` 产出 `room_server`、`client`；单实例可绑定 37404。

## 实验 7 同网段通告发现

责任人：刘。Tracker 关闭后，晚进客户端保持未进房，监听 UDP 37404 上的 `CMD_ANNOUNCE`，对房主 TCP 非阻塞直连（1.5 秒）并发送 `CMD_MANIFEST_REQ`。

| 项 | 值 |
|----|-----|
| 日期 | 2026-10-24（WSL Ubuntu，`LAP-NICKY`） |
| 网络 | 本机环回 / 同一 WSL |
| 端口 | Tracker TCP 37401、UDP 37402；通告 UDP 37404 |
| 入口 | D 窗 `./client`；同等路径可用 `./client_transfer`（`tr_connect_announced`） |

四窗步骤见 [`构建说明.md`](构建说明.md)。

| 阶段 | 操作 | 结果 |
|------|------|------|
| 在线通告（B/C 已 join） | 房主 `announce` | 侦探窗路径「通告发现」；在线成员不自动 `MANIFEST_REQ` |
| 关房四窗 | A 停止 `room_server`；B 连发 `announce`；D 保持未进房 | D：`peer 0` → `ANNOUNCE` → 已连接房主 →「正在索取清单」 |
| 清单 | 房主无本局 `session` 缓存 | `session=00000000`、顶栏「待清单」为预期；`ERR_NO_MANIFEST` |

发送：`punch_send_announce`。接收：`src/ui/client_main.c`；统一入口 `tr_connect_announced`。路径栏：`PATH_ANNOUNCE` →「通告发现」。通告限于本网。

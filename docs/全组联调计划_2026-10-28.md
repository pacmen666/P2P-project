## 5. 联调步骤（同网段）

端口：Tracker TCP **37401**、UDP **37402**；通告 UDP **37404**；中继 TCP **37405**。全程只用 **内网 IPv4**。

### 5.1 服务机（王，或约定的一台）

```bash
cd <仓库根>
./room_server          # 终端 1，保持运行
./relay_server         # 终端 2，保持运行
```

把该机 **内网 IP** 发给房主和侦探（下文写作 `TRACKER`）。

### 5.2 房主（彭或刘，机 A）

```bash
cd <仓库根>
export SESSION=session_1e22ca8e    # 或陈指定的目录
./client_transfer --host --session "$SESSION" --room TRACKER --nick 房主
```

若顶栏仍是离线 / peer 0，在案情板输入：

```text
join 房主 TRACKER host
```

确认：`房间服务：在线`，`我：房主 (peer 1)`，三文件本地已有。

### 5.3 侦探（刘，机 B）

```bash
cd <仓库根>
mkdir -p .cache/detective_lan
./client_transfer --room TRACKER --nick 侦探 --data-dir .cache/detective_lan
```

需要时：`join 侦探 TRACKER`。成员表见到房主后：

```text
get
```

等三证物「已有」，可输入 `stats`。

### 5.4 当场记录

- 路径栏是否为「本网直连」  
- `TRANSFER_STATS` 中 `relay_up` 是否为 0  
- `punch_hosts.md`：客户端 B 主机名  
- `experiment9_relay.md` 记录栏：日期、A/B、NAT 可写「同网段未测」、模式 tcp、结果

## 6. 失败时先查

- 两机能否 ping；37401 是否通  
- 是否误开了第二份 `room_server`  
- `--session` 是否目录路径、目录内是否有 `manifest.bin`  
- 房主是否在 Tracker 起来 **之后** join（先开 client 再开 room 会 `TRACKER_OFFLINE`，需再 `join`）

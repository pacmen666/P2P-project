# 文档

协议字段以约定为准。进度与状态以验收总表为准。课程设计以项目方案为准。

## 地图

| 文档 | 用途 |
|------|------|
| [`碎片档案_v1格式约定.md`](碎片档案_v1格式约定.md) | 协议：字段、端口、指令码（签字后字段只读） |
| [`碎片档案_项目方案.md`](碎片档案_项目方案.md) | 课程方案原文 |
| [`验收总表.md`](验收总表.md) | 编号、验收条目、责任人、状态 |
| [`进度与分工.md`](进度与分工.md) | 现行剩余工作 |
| [`实验记录.md`](实验记录.md) | 实验 0–9 书面记录 |
| [`现场讲解提纲.md`](现场讲解提纲.md) | 十五分钟演示 |
| [`模块对接.md`](模块对接.md) | 模块之间的接口 |
| [`传块模块.md`](传块模块.md) | 传块实现与单机回归 |
| [`界面与通告.md`](界面与通告.md) | 终端案情板、探测、关房通告 |
| [`案卷装载.md`](案卷装载.md) | 清单装载接口 |
| [`主机登记.md`](主机登记.md) | 演示主机与网段（无家庭公网地址） |
| [`构建说明.md`](构建说明.md) | WSL 构建、冒烟、关房四窗 |

源码旁的 `src/*/README.md`、`tests/README.md` 只说明该目录职责与命令，不重复协议正文。

## 规则

| 类别 | 说明 |
|------|------|
| GitHub | 只提交 markdown 等小文档 |
| 只读 | v1 约定的字段表、端口、错误码（签字后） |
| 可编辑 | 本 README、验收总表状态、实验记录补行 |

源码、成品案卷、pcap 不放在本目录。

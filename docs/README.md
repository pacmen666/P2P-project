## 规则

| 类别 | 说明 |
|------|------|
| GitHub | 只提交 markdown 等小文档 |
| gitignore | 无额外规则 |
| 本地 | 可另存实验草稿，定稿后再覆盖方案中的实验节或另开 `docs/experiments/` |
| 只读 | v1 约定的字段表、端口、错误码（签字后） |
| 可编辑 | 本 README；方案里的进度说明、演示顺序 |

不要把源码、成品案卷、pcap 放在这里。

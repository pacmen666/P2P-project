## 交付路径

| 路径 | 说明 |
|------|------|
| `include/ui_state.h` `src/ui/ui_state.c` `src/ui/ui_term.c` | 界面状态与终端案情板 |
| `include/punch.h` `src/punch/udp_sock.c` | 单一 UDP 文件描述符：PROBE / PUNCH / ANNOUNCE |
| `src/ui/client_main.c` | 网络线程 `select`、界面线程、唤醒管道 |
| [`主机登记.md`](主机登记.md) | 演示主机 |
| `Makefile` 目标 `client` | 构建 `./client` |

房间服务补发 `PROBE_ACK`。`client_transfer` 复用 `ui_state`、`ui_term` 与 punch。关房晚进 D 窗允许使用 `./client` 或 `./client_transfer`（`tr_connect_announced`）。

---

## 本机双进程

环境见 [`构建说明.md`](构建说明.md)。

```bash
make room_server client
./room_server
./client
```

```text
join 侦探 localhost
probe
```

房主另开终端：`join 房主 localhost host`，随后 `announce`。`JOIN_OK` 后案情板显示 peer 与昵称；`probe` 后反射行更新。清单到达时仅显示整文件摘要前缀。

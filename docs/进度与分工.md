## 4. 王侧剩余实验操作

### 4.1 实验 2

```bash
./room_server --iterative
```

两客户端几乎同时 `join`。记录后来者等待至先到连接处理完毕。随后改回 `./room_server`，再次同时 `join`。书面说明迭代阻塞原因与交付选择 `select` 的理由。

### 4.2 实验 5

客户端 `--room <hostname>` 使用本机 `hostname` 输出进房。对同一名字设置 `AI_NUMERICHOST` 后解析失败（预期），日志由 `src/common/config.c` 的 `resolve_host` 打印。另用 `getnameinfo` 将已连接对端表示为可读形式。

### 4.3 演示当日服务

1. 演示网络下虚拟机桥接，当前地址为 `172.20.10.x` 网段。  
2. 同机先启动 `./room_server`（UDP 37402 已监听），再启动 `./relay_server`。  
3. 将当前 IPv4 发给房主。地址随入网变化，程序无需重编译。  
4. 防火墙放行 TCP 37401、TCP 37405、UDP 37402。

VMware NAT 地址 `192.168.65.x` 不能作为全组 Tracker。

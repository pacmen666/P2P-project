## 单机回归

退出已在运行的 `room_server` / `relay_server` / `client_transfer` 后执行：

```bash
make -B test-transfer
```

同时出现 `ALL STREAM TESTS PASS` 与 `ALL TRANSFER INTEGRATION TESTS PASS`。测试自行起停子进程，占用 TCP 37401/37405、UDP 37402/37404。证据目录不提交进仓库。

Mac：Xcode Command Line Tools 与 Homebrew `openssl@3`。WSL：`build-essential`、`python3`、`libssl-dev`。

分项：

```bash
python3 -u tests/test_transfer.py --case tcp
python3 -u tests/test_transfer.py --case resume
python3 -u tests/test_transfer.py --case udp-once
python3 -u tests/test_transfer.py --case udp-all
python3 -u tests/test_transfer.py --case relay
python3 -u tests/test_transfer.py --case announce
```

| 用例 | 内容 |
|------|------|
| tcp | 三进程收发；Tracker 关闭、来源退出后仍完成；远端 HAVE 不令本机假完成 |
| resume | 重启复用缓存；损坏块重新校验 |
| udp-once | 丢选定子包，NAK 补齐，路径保持 UDP |
| udp-all | 丢全部 UDP 数据，有界重试后转 `relay_server` |
| relay | 完整文件经中继；粘包、错房间、伪造来源、慢接收方隔离 |
| announce | 本机 ANNOUNCE 到 37404。跨机器通告见实验 7 |

保留 `FAULT_DROP` 断言与既有超时。

## 本机三端演示

```bash
make transfer
./room_server
python3 tools/gen_case.py
./client_transfer --host --session <案卷目录> --room 127.0.0.1 --nick Host
./client_transfer --room 127.0.0.1 --nick Bob --data-dir /tmp/fragment-bob --auto
```

Bob 使用独立缓存目录。出现 3 条 `FILE_COMPLETE` 后输入 `stats`，退出输入 `quit`。强制中继时另开 `./relay_server`，双方追加 `--mode relay`，Bob 换空缓存目录。
